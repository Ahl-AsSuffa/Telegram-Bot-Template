# Telegram-Bot-Template
Небольшой шаблон Telegram-бота на C#, который можно использовать как основу для информационных ботов с меню и отдельными возможностями для администраторов.
Бот обрабатывает команду /start, показывает клавиатуру, отвечает на /help и выводит сообщение для неизвестных команд. Также в проекте предусмотрено сохранение списка администраторов в JSON-файл.

Возможности:  
 - Запуск бота через /start.
 - Отображение пользовательской клавиатуры.
 - Отдельная клавиатура для администраторов.
 - Проверка пользователя по Telegram ID.
 - Обработка команды /help.
 - Игнорирование сообщений из групповых чатов.
 - Обработка ошибок Telegram Bot API.
 - Пропуск старых обновлений после запуска.
 - Добавление и удаление администраторов.
 - Сохранение списка администраторов в admins.json.
 - Загрузка списка администраторов при старте.

Технологии:  
 - C#
 - .NET
 - Telegram Bot API
 - Telegram.Bot
 - System.Text.Json
 - JSON для хранения списка администраторов
 - Как работает бот
 - После запуска приложение загружает список администраторов из admins.json.
 - Бот пропускает старые обновления Telegram.
 - Начинается получение новых сообщений.
 - При команде /start пользователь получает главное меню.
 - Для администратора отображается отдельное меню.
 - Команда /help повторно выводит список доступных команд.
 - Неизвестные сообщения обрабатываются стандартным ответом.  

Проект является базовым шаблоном Telegram-бота с меню, проверкой администраторов и файловым хранением списка пользователей с правами администратора.
